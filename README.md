# Alerta Cidadão

Sistema de alerta de enchentes que mede o nível da água em tempo real e avisa os moradores com orientações simples, antes que a água chegue às casas.

Projeto acadêmico · Global Solution 2026 · FIAP

## Páginas

- `index.html`: início, com simulador do nível da água
- `problema.html`: por que as enchentes pegam os moradores de surpresa
- `tecnologia.html`: como o sensor mede a água e gera o alerta
- `objetivos.html`: avisar cedo, orientar com clareza e proteger vidas
- `publico.html`: quem mais precisa do aviso
- `beneficios.html`: o que muda para as famílias e a comunidade

## Estrutura

```
css/style.css   estilos do site
js/main.js      menu no celular e simulador
images/         ícone do projeto
```

Baixe o repositório e abra o arquivo `index.html` no navegador.
